# Job Consultancy

A responsive healthcare job consultancy landing page for Abhi Resource Management. The site presents healthcare placement services, doctor profiles, hospital partners, featured job openings, and direct contact options for candidates and employers.

![Job Consultancy homepage preview](home-check.png)

## Features

- Healthcare-focused landing page with doctor and hospital imagery
- Responsive navigation, hero section, service blocks, job listings, and footer
- Featured specialist carousel-style section
- Hospital partner/logo showcase
- WhatsApp, phone, and email contact links
- Custom CSS refinements for alignment, image quality, and mobile responsiveness

## Tech Stack

- HTML5
- CSS3
- Bootstrap
- Font Awesome
- Swiper
